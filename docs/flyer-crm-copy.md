# Partner flyer → CRM paste sheet (NG Home Cleaners)

Source: Clean Haven Solutions partner flyer (checklists / add-ons only).  
Where: `/admin` → **Services** / **Add-ons**.  
Do not: `migrate:fresh` or re-seed production.

---

## How to use

1. Open each service by slug below.
2. **Overview** tab → paste field values (replace current).
3. **Service details → Inclusions** → delete old rows, then either:
   - **Add inclusion** for brand-new wording, or
   - **Add from library** and tick items already created on another service.
4. **Service details → Exclusions** → same pattern (library multi-select or add new).
5. **Add-ons** → create/update, then on each service tick **Optional add-ons**.
6. Leave **slug** unchanged so URLs stay stable.

Tip: update **Regular clean** inclusions first, then on Deep / Office use **Add from library** for shared lines.

## 6. Seeded exclusions you can retire

Global seed exclusions often appear on every service. After pasting the tables above, remove or rewrite any that contradict the flyer (examples):

- *Laundry, ironing or making beds with fresh linen* → replace with add-on note if you offer **Change bed linen**  
- *Inside oven, fridge or freezer on a regular clean* → keep the idea, use the clearer task/note rows above  
- *Hoarding clearance…* / *Biohazard…* → optional keep for safety; not on the flyer
